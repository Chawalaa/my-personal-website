# The Unconventional Mind

An editorial and interactive personal website starter for Hope Chawala Banda.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Deploy

Push the project to GitHub and import the repository into Vercel. Framework preset: Next.js.

## Customize before publishing

- Replace `hello@example.com` in `app/page.tsx` with your real public contact email.
- Add real essay links and published works; the Writing entries are explicitly placeholders.
- Add project detail pages and demo URLs when ready.
- Add your own professional portrait and photography if desired.
- Review all biographical text and project descriptions.
- Adjust the palette and layout in `app/globals.css`.

## Features

Responsive layout, mobile navigation, interactive question explorer, featured project cards, editorial writing previews, and contact section.
